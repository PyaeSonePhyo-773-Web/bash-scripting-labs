# Bash Scripting Labs

## Overview

This repository documents my journey learning Bash scripting and Linux automation.

The scripts are developed and tested in a Linux environment as part of my preparation for Linux Administration and Cloud Engineering roles.

## Learning Topics

* Bash fundamentals and variables
* User input and command substitution
* Conditional statements and loops
* Functions and script arguments
* Linux system administration
* Log analysis and monitoring
* Backup automation and error handling

## Repository Structure

* `01-basics/` — Beginner Bash scripts
* `02-conditions/` — Conditional statements
* `03-loops/` — Loops and iteration
* `04-functions/` — Reusable Bash functions
* `05-system-administration/` — Linux administration scripts
* `06-projects/` — Practical automation projects

## Environment

* Operating System: MSI Window
* Shell: Git Bash
* Version Control: Git and GitHub

## How to Run a Script

Clone the repository, enter the project directory, and execute a script:

```bash
chmod +x 01-basics/hello.sh
./01-basics/hello.sh
```

## Project Goals

* Build practical Bash scripting skills.
* Automate repetitive Linux administration tasks.
* Develop troubleshooting and monitoring skills.
* Prepare for Linux Administration and Cloud Engineering opportunities.

This repository is continuously updated as I learn new concepts and build practical projects.
